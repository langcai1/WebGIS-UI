# 项目名称
森林病虫害监测 WebGIS 前端 UI 原型

# 项目类型
纯前端 Vue 3 + TypeScript WebGIS UI 原型。只使用 mock 静态数据，不连接后端、不连接 GeoServer、不连接 PostGIS。

# 一、项目背景
本项目用于展示林区病虫害灾害点、灾害斑块、风险等级、巡护记录与防治任务。系统面向林业管理人员、森林防护站和巡护人员，用于快速了解区域森林健康状态，并辅助判断重点防治区域。

# 二、技术栈要求
- Vue 3
- TypeScript
- Vite
- Pinia
- Element Plus
- Leaflet 或 SVG/Canvas 地图占位
- CSS 或 SCSS
- mock 静态数据

# 三、页面结构
项目至少包含以下页面：
1. 首页总览 Dashboard
2. 森林病虫害监测地图 MapView
3. 防治任务与巡护记录 TaskView
4. 关于页面 AboutView

# 四、首页总览 Dashboard 要求
首页应体现“森林健康监测中心”的感觉，不能只是普通卡片堆叠。

必须包含：
- 顶部标题栏：系统名称、当前区域、更新时间、用户入口
- 核心指标卡片：
  - 监测林区面积
  - 病虫害事件数量
  - 高风险斑块数量
  - 本周新增巡护记录
- 风险等级分布模块：低风险、中风险、高风险、紧急处置
- 今日预警列表：显示病虫害类型、位置、风险等级、发现时间
- 林区健康趋势图：可使用 mock 折线图或 CSS/SVG 简化图
- 重点防治区域列表：显示区域名称、虫害类型、处置状态

# 五、地图页面 MapView 要求
地图页面是系统重点，布局应具有 WebGIS 工作台风格。

必须包含：
- 中央地图区域，可以使用 Leaflet、SVG 或 Canvas 占位
- 左侧图层控制面板：
  - 林区边界
  - 病虫害中心点
  - 病虫害斑块面
  - 风险热力图
  - 巡护路线
- 右侧详情面板：
  - 当前选中病虫害区域信息
  - 虫害类型
  - 影响树种
  - 发生面积
  - 风险等级
  - 建议处置措施
- 底部时间轴：
  - 最近 7 天 / 30 天 / 90 天切换
  - 病虫害扩散趋势节点
- 地图上要模拟不同尺度展示：
  - 远距离：使用病虫害图标点
  - 中距离：图标 + 光晕热点
  - 近距离：显示病虫害斑块 polygon + 中心点 + 标签

# 六、TaskView 要求
用于展示防治任务和巡护记录。

必须包含：
- 防治任务列表
- 巡护记录列表
- 任务状态：待处理、处理中、已完成、复查中
- 可视化小组件：任务完成率、重点区域数量、今日巡护里程
- 任务详情卡片

# 七、mock 数据要求
必须在前端项目中创建 mock 数据文件，不得请求真实接口。
建议 mock 数据包括：
- forestLayers
- pestEvents
- riskZones
- patrolRoutes
- preventionTasks
- forestStatistics
- timelineEvents

# 八、视觉风格要求
整体风格应为“自然生态 + 专业监测”：
- 主色：森林绿、苔藓绿
- 辅色：浅米色、浅灰绿
- 风险色：黄色、橙色、红色
- 地图底色应偏浅，不要使用强烈深色科技风
- 卡片圆角适中，阴影柔和
- 信息密度中等，适合管理端系统
- 不要生成花哨的游戏风、赛博朋克风或纯黑背景

# 九、UI 质量要求
- 页面必须可运行
- 布局不能塌陷
- 组件命名清晰
- 数据应来自 Pinia store 或 mock 数据模块
- 首页、地图页、任务页之间风格统一
- 地图区域必须占页面视觉中心
- 所有指标、列表、面板都要有真实 mock 内容
- 不允许出现大量 Lorem ipsum
- 不允许出现空白主区域

# 十、交付要求
生成完整 Vue 3 前端项目文件，输出到 outputs/generated_frontend。
